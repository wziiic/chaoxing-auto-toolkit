# 学习通辅助面板

基于 Python、FastAPI 和 Playwright 的本地学习通辅助工具，提供 **作业面板** 和 **课程学习** 两个页面。支持复用自己的学习通桌面端登录会话，并通过兼容 OpenAI 协议的模型服务处理可识别的练习题。

面板运行在自己的电脑上。课程状态以平台反馈为准，进入章节、滚动到底或播放结束都不会直接当作任务完成。

## 下载

- **直接下载**：[下载项目 ZIP](https://github.com/wziiic/chaoxing-auto-toolkit/archive/refs/heads/master.zip)，解压到一个固定目录，例如 `D:\学习通面板`。不要在压缩包内直接运行。
- **使用 Git**：

```powershell
git clone https://github.com/wziiic/chaoxing-auto-toolkit.git
cd chaoxing-auto-toolkit
```

下载的是源码包，需要安装下面的运行环境。

## 安装和启动

准备 Windows、Python 3.9 或以上版本，以及已安装并登录的学习通 Windows 桌面端。安装 Python 时勾选 **Add python.exe to PATH**。本机使用 Python 3.10 验证。

建议电脑上安装 Chrome 或 Edge。可在 **设置 → 启动设置 → 默认打开的浏览器** 中选择系统默认、Google Chrome、Microsoft Edge 或其他浏览器的完整 `.exe` 路径。选择 Chrome / Edge 时，新建课程窗口也使用该浏览器；选择系统默认或其他浏览器时，课程内核按 Chrome → Edge → Playwright Chromium 尝试。课程窗口不会接管你日常浏览器的个人配置目录。

1. 解压或克隆项目后，双击根目录的 **`启动面板.bat`**。
2. 首次启动会检查并安装 Python 依赖，创建或修复桌面“学习通面板”齿轮图标快捷方式。
3. 面板启动后，浏览器会打开 [本地面板](http://127.0.0.1:8765/)。启动终端请保持运行，关闭会停止服务。
4. 点击右上角 **设置 → LLM 设置**，填写服务地址、模型名称和自己的 API Key，先保存，再测试连接。两个页面共用这份模型配置。

若没有可用浏览器内核，可在项目目录执行：

```powershell
python -m playwright install chromium
```

也可以手动安装和启动：

```powershell
python -m pip install -r requirements.txt
python -B panel/app.py
```

桌面快捷方式使用仓库附带的齿轮图标。移动项目后，请从新目录再次运行 `启动面板.bat`，更新快捷方式目标及图标路径。

## 作业面板

入口：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

- 读取作业列表，筛选和选择待处理作业。
- 获取作业页面并提取题目，支持批量抓题与模型作答。
- 查看答案、暂存、核对结果及按页面操作提交。
- 使用已知答案进行模型基准测试。
- 右上角提供刷新列表、重载页面和设置入口。

作业页默认配置为暂存，不自动交卷；请查看答案及页面反馈后决定是否提交。

## 课程学习

在顶部点击 **课程学习**，或打开 [http://127.0.0.1:8765/study](http://127.0.0.1:8765/study)。

### 使用步骤

1. 点击 **读取课程**，从课程选择窗口查看未完成、状态未知或全部课程；选中后自动填入链接。也可以粘贴自己的课程学习页链接，在选课窗口点击“读取输入的链接”。
2. 读取过程使用后台无窗口浏览器，只读取课程目录，不先逐章遍历任务。课程选择窗口固定大小，列表内部滚动；目录就绪即可开始设置。
3. 选择课程后自动滚动到 **学习与播放队列**。先确认自动填写、自动提交、自动提交讨论、播放时静音、播放速度以及遇到人工任务时暂停或继续的策略，再点击 **开始学习** 或 **开始选中任务**。勾选“播放时静音”后，视频和音频将静音播放，切换任务或题目处理后恢复播放仍保持静音；该选项会随学习设置保存。播放中修改学习设置会先暂停，点击继续后生效。读取课程本身不会开始执行。进入当前章节时再识别其中全部学习步骤与任务点，处理完后继续下一章，不需要等整门课扫描完毕。
4. 在任务表、统计区和运行日志查看具体任务的进度、平台状态及失败原因。可随时暂停、继续或停止。

同一窗口反复打开选课列表会沿用首次读取结果，不再按时间自动重读；读取失败后也需要手动刷新重试。需要重新核对时点击 **刷新课程列表**。再次选择当前已读取、且链接身份和签名未改变的课程，会沿用目录和任务状态；点击 **刷新任务状态** 才重新读取当前课程目录。

若提示读取中断，请查看选课窗口上方的原因。登录失败时不会继续假装加载，也不会自动反复读取：可先打开课程窗口完成登录，再手动刷新课程列表。桌面端登录文件被占用或无读取权限时，会尝试复用本机已有的 Windows 加密登录备份；仅在新建课程浏览器时读取，不自动保存、不周期性导出浏览器状态。备份失效或不存在时仍需本人登录。

### 多课程播放队列

在课程学习页的 **学习与播放队列 → 选择多门课程** 中勾选课程，点击 **加入队列**。可搜索、筛选课程，用 **上移 / 下移** 调整顺序，或用 **加入当前课程** 添加已经读取的课程。选择顺序就是初始播放顺序。

确认下方静音、倍速、练习与讨论设置后，点击 **开始队列**。后台按顺序学习，一门课程的任务全部经平台核验完成后，自动进入下一门；同一时间只执行一门课程。已有目录与完成记录会继续复用，新课程在执行到时读取目录并按章识别任务。

每次开始或继续时，按课程目录顺序定位第一个未完成任务点，不直接沿用旧的章节位置。已核验完成且平台状态为完成的章节沿用缓存并跳过；未检查章节及状态不一致的任务会先核验，原页面已经完成的任务不再播放、答题或滚动。选择单个任务时仍只处理明确选中的任务，不扩展到整门课程。

目录完整性同时兼容平台原生目录接口：接口返回的完整章节顺序必须与页面一致，加载中、筛选结果、缺少编号或响应失败均不会当作完整目录。旧记录因读取中断而留下不完整标记时，继续队列会重新核对目录，保留已完成记录，并继续识别新增章节，避免任务已完成却无法自动换课。

单课程与多课程共用一组 **开始、暂停、继续、停止** 控制按钮，按钮会随当前模式显示“开始学习”或“开始队列”；有待执行课程时优先执行课程队列。多课程按整门课程执行，单独选择任务及重试入口需先清空课程队列。支持 **移除课程、清空队列**，最多保存 50 门课程。遇到登录失效时按自动登录设置恢复；仍无法登录、待核验或人工处理时会保留当前位置并暂停。也可明确点击 **跳过本课程并继续**，跳过项单独统计，不视为课程完成。限次练习的单独授权不会跨课程继承。

队列顺序、状态与进度保存在本机，重载网页不会中断后台学习；后台重启后保留队列，但需点击 **继续队列** 恢复。单课程正在学习时，先暂停再开始多课程队列。

### 启动设置

在右上角 **设置 → 启动设置** 中可选择：

- **学习通账号与自动登录**：输入自己的手机号 / 超星号和密码，勾选“登录失效后自动重新登录”并保存。凭据通过 Windows 当前用户加密保存在本机学习数据库，接口只显示掩码，不回传密码，也不会发送给 LLM。账号和密码留空时沿用已保存内容，更换账号需同时输入密码；支持删除保存的账号密码。保存本身不启动学习。
- **登录恢复**：学习或读取过程中发现登录失效，会通过学习通官方登录页自动登录，再核验并继续原课程或多课程队列，保留原设置与提交防重记录。密码错误、验证码、扫码或身份验证时暂停提示，不自动绕过验证；一次失败后停止尝试，短时间再次失效也不会反复登录。完成验证后点击继续，或更正账号密码后保存。当前已经暂停的课程，首次配置完成后点击继续即可。
- **启动时自动读取课程**：默认关闭。开启后，新窗口启动时读取课程列表，不会自动开始学习或提交。
- **默认打开的浏览器**：系统默认、Chrome、Edge 或自定义浏览器。自定义填写浏览器程序完整路径，不附加启动参数；保存时会检查是否已安装。浏览器选择保存在本机面板，两页共用，下次启动面板或新建课程窗口时生效，不会中断当前课程。通过收藏夹或手动粘贴地址打开时仍使用你操作的浏览器。
- **课程窗口网络连接**：跟随系统或直连。代理导致加载慢时可尝试直连，新建课程窗口后生效；不改变系统代理、飞书或日常浏览器。网络必须经过代理时保留系统模式。
- **启动页面**：跟随打开地址、上次使用的页面、作业面板或课程学习。
- **恢复上次课程搜索和筛选**、**显示加载时的猫娘提示**。
- **课程任务进行中重载前提醒**：提醒重载网页不会停止后台任务。

浏览器选择保存在本机面板，其余偏好保存在当前浏览器；更换浏览器后可重新设置这些偏好。启动选项在下次打开新窗口时生效。

### 基本功能

- **边学边识别**：先读取目录即可开始，学习时按章发现任务并更新列表；同章多个学习步骤全部检查，后台不会另开扫描抢占播放器。
- **按任务点统计**：支持多层章节和同章节多个任务，不把进入章节视为完成。未检查章节明确标注，任务总数尚未确定时只显示已发现数量。
- **视频、音频**：定位屏幕下方和嵌套 iframe 内的播放器，正常播放并跟踪进度；平台不支持所选倍速时回退 1×。播放结束后重新核验完成状态。
- **阅读、课件**：滚动任务内部的阅读区域和嵌套 iframe 到底部；延迟追加的内容会再次检查。页面有明确计时或翻页要求时按要求处理，再核验平台状态并继续后续任务。
- **正文图片**：通过附件资源 ID 与页面图片唯一匹配识别参考插图，兼容没有 `_jobid` 属性的普通图片。不把插图计为必做任务；有任务标记、标识冲突、重复资源或匹配不明确时保留核验，不推定完成。
- **链接阅读**：通过对应任务卡片的原生入口打开链接，再核验平台任务状态；不把网页打开成功当作任务完成，已打开的任务只核验，避免重复打开。
- **普通练习**：提取题目、调用共用模型配置，校验结果、填写后回读；启用自动提交后处理可识别的确认弹窗，并检查页面反馈和平台状态。
- **判断题格式校验**：原生判断控件使用字符串 `true` / `false` 时，兼容模型的等价 JSON 布尔值。其他不匹配答案仍严格拒绝；非空答案有格式错误时只重新校正一次，未通过前不填写、不提交，模型生成失败不占用平台作答次数。不确定的空答案不猜测。
- **限次章节练习授权**：在学习设置勾选“授权当前课程的限次章节练习”，授权仅对当前课程身份生效，多课程切换不会给其他课程自动授权。可取消勾选撤销，正式考试仍需手动处理；平台的次数、锁定与提交结果核验继续保留。单独选中任务的授权入口也保留。
- **视频弹题**：识别原生弹题，复用同一模型配置作答；提交并确认结果后点击平台“继续学习”。同一视频多次弹题分别防重，答错或反馈不明确时转人工核查，不强行恢复播放。
- **讨论**：勾选学习设置中的“自动提交讨论”，会读取必做讨论题目，调用已配置的 LLM 生成简短、口语化正文，再通过页面填写、提交并核验。默认不勾选；已有草稿优先使用，发布待核验时不重复提交。非必做讨论仍需单独开启队列自动发布。也可在任务行编辑正文、保存草稿或手动发布。
- **飞书或旧客户端启动**：请求未携带“自动提交讨论”“播放时静音”时，沿用面板保存的选择；明确传入关闭值才会关闭。首次使用仍默认关闭。
- **记录保留**：保留上次课程链接、目录、设置、选择及执行位置。手动读取或刷新只更新课程目录；任务在进入章节时实时识别。恢复时重新核验当前位置，已核验章节沿用缓存。
- **运行控制**：串行队列、有限重试、暂停取消旧响应、提交防重和同课程实例锁。支持导出脱敏记录。
- **断网自动恢复**：视频、音频遇到确认的网络中断时保留当前任务与进度，显示“等待网络恢复”，连接恢复后自动重载当前任务并沿用静音、倍速设置，不重扫整门课、不消耗额外任务重试次数。播放位置以平台保存记录为准，可能重播最近尚未上报的一小段。手动暂停、停止、关闭课程窗口或平台限制不会自动恢复；题目、讨论提交结果不明时仍需核验，不自动重复提交。
- **讨论内容加载恢复**：题目为空或任务区域延迟加载时先等待；仍为空时等待网络可用并重新读取当前任务一次。重连后重新核对任务状态，已完成则跳过，不重扫课程、不重复发布；二次读取仍无题目时暂停提示人工核查。等待期间支持暂停、停止。
- **媒体状态加载恢复**：新进入的视频或音频状态未知时，先短暂等待，必要时重新连接当前任务一次；无法确认时仍暂停，不猜测任务状态。网络失败日志保留主机、资源类型及 `ERR_NETWORK_CHANGED` 等错误码，隐藏签名链接和查询参数，便于区分网络切换与播放器问题。
- **页面加载时网络切换**：明确观察到 `ERR_NETWORK_CHANGED` 且课程目录加载超时，或导航本身被网络切换中断时，对同一课程页面自动重连一次；不循环刷新，不对登录跳转或身份验证自动重试。
- **课件就绪与恢复**：原生 PDF/PPT 阅读器的当前可见页面实际渲染后才执行阅读，空白 iframe 不计为读完。阅读器连续 60 秒未就绪时重连当前任务一次；滚动后仍未获平台确认时，可有限地重新定位阅读。只有阅读任务允许这种重试，题目、讨论、链接的提交或打开记录继续保留防重。面板显示等待加载、阅读及核验阶段，完成仍以平台反馈为准。
- **睡眠与模型连接恢复**：Windows 学习队列运行期间临时阻止系统因空闲自动睡眠，暂停、停止、完成或出错后释放，不修改电源计划。系统被手动睡眠或强制挂起后，媒体监测到长时间中断会重新连接当前任务；平台要求窗口可见、用户手动暂停等限制仍保留。模型生成遇到临时断网、超时或 TLS 连接中断时最多自动重试 5 次，重试阶段不填写、不提交，也不重复发布讨论；证书校验、模型配置错误仍需人工处理。电脑实际睡眠时程序无法运行，唤醒后才能恢复。
- **统一设置**：两页右上角均提供重载页面和设置入口，包含 LLM 设置、启动设置。

点击“开始学习”或“打开课程窗口”才会显示课程浏览器；普通读取与刷新使用无窗口模式。它与显示本地面板的浏览器窗口相互独立。

已选课程时，“打开课程窗口”优先进入这门课，避免误打开后台读取用的原始课程列表；已经位于同一门课时保留当前章节，不为显示窗口而重复刷新。后台 PowerShell、依赖安装、任务子进程和快捷方式查询采用创建时隐藏，不通过弹出后关闭实现；其输出和错误仍由原调用流程接收。

后台播放由课程规则决定。有些课程会在鼠标移出窗口时暂停，即使窗口仍可见且有焦点；此时面板会保留进度并说明原因，返回课程窗口后点击继续。系统最小化短测可继续播放不代表该课程允许长期后台学习，平台任务完成仍需实际核验。面板不会伪造可见状态、鼠标活动或学习上报。

## 当前限制

- 需要自己的有效登录会话。登录失效、验证码、身份验证、访问限制或多设备冲突会暂停，需在原页面处理。
- 自动答题适用于已适配的普通练习；正式考试保留人工处理。限次或不可重做练习需要查看限制并单独授权。
- 图片题、特殊控件、不可访问的 iframe 和未支持的任务类型可能需要人工处理。模型输出不保证正确。
- 滚动到底和播放结束不等于平台完成；缺少明确平台反馈时保留待核验状态。不会伪造学习时长、心跳或完成记录。
- 讨论已适配预览卡片、话题页“回复”入口和编辑器延迟初始化。提交结果以平台回执或新回复编号核验；遇到平台拒绝会显示原因，待审核或结果不明时保留待核验，避免重复发表。

更详细的队列行为、验证记录和接入限制见 [课程学习说明](docs/课程学习.md)。

## 常见问题

- **有任务进度却显示“暂无法读取”**：课程进度与跳转脚本可能分批加载。面板会等待入口函数就绪，并兼容平台在新标签页生成学习链接；读取过程仍在后台进行。更新后先重载面板，再刷新课程列表。若提示入口脚本超时，请待网络恢复后重试，已读进度不会被当成课程完成。

- **停在知识图谱，视频没有开始**：网页智能助教脚本或章节内容可能仍在加载。面板只对已知的智能助教附属脚本设置 8 秒等待上限，超时会提示网页助教可能不可用；课程、题目及平台校验照常加载。目录出现后还会等待章节内容初始化，未就绪会明确报错，不会当作无任务或已完成。若持续超时，请检查系统代理和课程站点连接。

- **找不到 Python**：重新安装 Python 并勾选加入 PATH，重开终端后运行启动脚本。
- **未检测到学习通登录状态**：打开学习通 Windows 桌面端登录自己的账号，再重新读取。浏览器里已登录不代表桌面端已有可复用会话。
- **模型连接失败**：在 LLM 设置中检查地址、模型名称和密钥；修改后先保存再测试。
- **修改代码后仍是旧界面**：点击重载页面。后端代码更新还需要停止并重新启动服务；学习中应先暂停或停止队列。
- **桌面图标丢失**：确认项目没有被移动或删除，再运行 `启动面板.bat` 修复快捷方式。
- **环境排错**：在项目目录执行 `python doctor.py`。只检查依赖、不启动面板可运行 `python bootstrap.py --check --no-install`。

## 本地数据与更新

部分章节练习使用自定义字体：面板会在本机按当前页面字形还原题干和选项，避免将看似正常、实际读取为乱码的内容交给模型。字形无法精确识别时会暂停，不会猜字或提交。字体参考表及 MIT 许可位于 `panel/assets/`，运行时不请求外部字体识别服务。

播放时若页面仍可见、有焦点且网络正常，但鼠标移出后播放器暂停，面板会尝试一次原生继续。再次暂停则保留进度并等待处理；用户主动暂停、隐藏页面、答题弹窗和平台任务数量或时长限制不会被自动续播覆盖。

同一章节中可以同时存在必做任务和参考 PDF、视频、音频或链接。面板核对资源身份与卡片是否唯一对应，并检查平台任务标记；确认没有必做证据后作为参考资料保留，不再等待不存在的完成回执，也不会增加已完成任务数。有明确完成标记的资源仍按平台完成状态核验。

练习或讨论生成期间遇到模型网络、代理异常时，面板先等待连接恢复，连续两次确认服务可达后才重试生成，避免离线时耗尽重试次数。连通探测不携带题目、密钥或登录资料，沿用系统现有代理和 TLS 校验；等待期间可以暂停或停止。证书、账号配置错误及平台提交回执不明确时仍会停止自动操作。

`panel/config.json` 保存模型配置，`panel/study-data/` 保存课程记录及本机加密的课程链接；Cookie、作业页面与答案也只应保留在自己的电脑上。这些运行数据已加入 `.gitignore`，不要手动上传。

Git 安装的用户可在停止服务后运行 `git pull --ff-only` 更新代码，再重新启动。ZIP 用户可下载新版解压到新目录，并在备份后将自己的 `panel/config.json`、`panel/study-data/` 和需要的本地作业记录迁移过去。加密课程链接仅供原 Windows 用户使用，不适合随项目分享。

## 项目结构与验证

- `panel/app.py`：FastAPI 路由、原有模型调用和后台作业接口。
- `panel/static/`：作业页、课程页、共用页头和 LLM 设置组件。
- `panel/study_service.py`：课程队列、状态机、模型答题和提交保护。
- `panel/study_browser.py`、`study_directory.py`、`study_dom.js`：浏览器会话、课程目录、任务识别及页面操作。
- `panel/study_core.py`、`study_questions.js`、`study_discussion.py`：持久化与锁、题目适配及讨论流程。
- `lxt.py`、`list_works.py`、`batch_resolve.py`：原有作业核心功能。
- `bootstrap.py`、`tools/make_shortcut.py`：启动、自检与快捷方式维护。
- `tests/`：合成页面、模拟模型及队列测试。

测试命令：

```powershell
python -B -m unittest discover -s tests -p test_study.py
python -B tests/check_study_ui.py
```

测试主要使用合成页面和模拟模型，不连接真实模型或向真实课程提交。已有真实课件滚到底、视频短时播放及单条讨论发布并完成任务点核验的记录；这不代表所有课程、完整观看或真实交卷均已验证。
