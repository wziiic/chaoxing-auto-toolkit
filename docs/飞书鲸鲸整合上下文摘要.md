# 飞书鲸鲸与学习通面板：整合参考上下文

整理日期：2026-11-15。依据本机源码和已有说明，不代表重新验证了所有外部服务。用于后续跨项目协作；本次未搬迁目录、合并数据库、改动机器人项目或发送飞书消息。

## 项目职责与入口

- `D:\飞书鲸鲸\campus-feishu-agent` 是当前 Python 主 Agent，入口 `app.main`，通常由 `app.supervisor` 管理；健康端口默认 18765。飞书消息、会话、去重、持久任务及投递由该主入口负责。
- 根目录 Node 模块提供受控本地业务扩展，主要通过 `scripts/agent-bridge.js` 的 JSON IPC 被 Python 调用。`primary-runtime.json` 指定 Python；旧 Node 服务不能同时接收同一飞书应用的消息。
- `D:\学习通面板` 负责本地 HTTP 面板、课程目录与任务状态、浏览器控制和队列执行；默认端口 8765。两个项目已通过本地接口衔接，尚不是完成迁移的单一项目。

## 已有衔接代码

- 飞书 `app/study_panel.py`：`StudyPanelClient` 读取面板配置端口及访问口令，访问本地接口，明确关闭环境代理。不存在“机器人健康正常就代表学校登录正常”的关系。
- 飞书 `app/study_flow.py`：本人私聊身份检查、课程选择与后续流程；`app/study_progress.py`、`app/study_monitor.py` 负责进度与提醒相关处理。
- `scripts/study-panel.py`：检查或启动本地面板，读取受限任务摘要；启动锁防止重复进程。`study-panel-host.py` 加载现有面板应用，不经依赖安装或另建学习引擎。
- `scripts/study_panel_window.py`：飞书入口另用专属配置目录打开后台 Edge 面板窗口，有复用和不抢焦点逻辑。它与面板自身的默认浏览器设置是两条启动路径，尚未统一。
- 面板页面浏览器与 Playwright 课程浏览器是两种窗口。后者使用独立上下文，尝试复用桌面学习通会话；不能将日常浏览器、飞书 Edge 窗口、面板课程窗口的登录状态视为天然共享。

## 整合时保留的约束

1. 一个飞书消息入口、一个课程执行队列及课程锁；避免两个项目同时导航或控制同一门课。
2. Python 主 Agent 的会话与投递数据库、Node 来源与校园业务数据库、面板课程数据库暂保留各自职责；迁移前设计数据归属和备份，不直接拼接 SQLite 文件。
3. 配置区分主 Agent 模型、面板模型、校园授权、浏览器与网络偏好；不能互相覆盖密钥。凭据保留在受忽略的本机文件中，不进入摘要、机器人卡片或 Git。
4. 私人课程查询沿用本人私聊校验。提交类操作保持现有授权、判定和防重边界，不因整合而放开模型任意调用接口。
5. “文件存在”“配置已填”“健康接口可用”“真实学校会话有效”分别表达；登录过期需要实际重新登录，不能靠守护进程延长授权寿命。
6. 统一启动路径时，让飞书入口复用面板浏览器/网络偏好，并保留其现有后台、不抢焦点和窗口复用行为；目前仅记录差异，未改机器人项目。

- 面板状态曾为 paused，日志多次报告网络请求失败和章节内容加载超时；采样时浏览器 CPU 占用不高。
